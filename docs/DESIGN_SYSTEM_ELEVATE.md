# Card Stock Press — elevate design system (from assets)

Derived from `docs/IDENTITY.md` + `public/art/*` (card-stock, brand-mark). Not a reseed.

## Tokens
- Paper: `#f6f2e9` / `#eee6d8` / card `#fffcf7`
- Ink: `#1f1e21` / mute `#5a575c`
- Coral action: `#d94a5c` (punched; not vibe purple)
- Type: Literata (display) + Source Sans 3 (UI) + IBM Plex Mono (counts/wiki)
- Space: `--space-1…4`; desk rail `--desk-rail: 200px`

## Patterns
- Writing surface first (Bear): underline search, hairline tabs, no pill chrome
- Card overview (Craft): white stock cards, color only on left tab
- Tags from content: `#tag` text, not product chrome pills when possible
- Flat materials only — no soft gradients / glass

## Do
- Keep ruled stock on `.card-rules` only
- Prefer cut over decoration

## Don't
- Inter / Geist / Space Grotesk
- Soft Index Drawer revival
- Gelica photography cosplay
