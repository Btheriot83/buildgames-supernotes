# Critic vs live original — Inkwell / Supernotes

**Judge role:** independent (did not author the app).  
**Bar opened live:** https://supernotes.app/ (marketing home) + https://supernotes.app/pricing  
**Evidence:** `docs/original-supernotes-home.png`, `docs/original-supernotes-pricing.png`  
**Candidate evidence:** `docs/live-inkwell-desk.png`, `docs/live-inkwell-editor.png`, `docs/live-inkwell-export.png`  
**Candidate live:** https://buildgames-supernotes.vercel.app

## What the original sets as the bar
Supernotes sells **notecards** as the unit of thought: short cards, hierarchy/filters, links + graph, share/collab, cross-device. Marketing is light, airy, serif headline + coral/pink CTAs, generous whitespace. The paid product promise is speed + polish + sync — not a blank markdown file.

## Candidate read (screenshots + core loop)
Inkwell takes a **different aesthetic thesis** (dark ink desk + warm paper cards + mint) rather than cloning the light pink landing. That is the right call for anti-slop and “replacement craft.” Core loop is honest: SAMPLE cards, collections/tags, instant search, `[[wiki]]` backlinks in the editor, Markdown zip export with success-check. Chrome is restrained; type has an opinion (Fraunces / IBM Plex).

## Scores (craft vs original product bar)

| Dimension | /10 | Notes |
| --- | --- | --- |
| Notecard metaphor clarity | 9.0 | Cards feel like the product; SAMPLE labelling is clear |
| Capture → link → find loop | 8.8 | Search + wiki backlinks work; no graph view (paid advantage) |
| Information density / hierarchy | 8.5 | Sidebar collections/tags solid; missing nested parent/child cards |
| Visual craft / anti-slop | 9.1 | Distinctive desk; no purple gradient / Inter / 3-up hero |
| Motion / transitions.dev | 8.7 | Tilt, panel slide, tabs, toast, success-check wired in real UX |
| Export / ownership | 9.0 | Zip of `.md` with frontmatter beats “screenshots only” replacements |
| Parity with collab/sync | 6.5 | Deliberately cut — scores honesty, not feature race |
| **Overall** | **8.8** | Strong polish contender for local-first notecards; not a full Supernotes clone |

## Biggest gaps vs original
1. No live graph / spatial map of links  
2. No realtime share or multiplayer  
3. Body is plain/`[[wiki]]` — not rich embeds, math, checklists UI  
4. Single-device IndexedDB only  

## Verdict
Ship-ready as a **local notecard desk** replacement for the core “small linked cards” job. Overall **8.8 / 10** against the live original bar. Opened live original: **yes**.
