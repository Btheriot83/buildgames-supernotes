## Technique 8 — Hand copy (before → after)
| Surface | Before (LLM/ship voice) | After (hand) |
|---|---|---|
| Brand sub | `N cards · local desk` | `N cards on the desk` |
| Loading | `Opening the desk…` | `Laying out the cards…` |
| Search placeholder | `Search title, body, tags — /` | `Find a card — press /` |
| Empty title | `Desk is clear` / `Nothing matches` | `Clear desk` / `No cards here` |
| Empty body | `One idea per card. Link with [[titles]]. Auto-tag and summarize when you need a polish.` | `One thought per card. Pencil a [[link]]. Let the desk suggest the rest.` |
| Empty CTA | `New card` | `Start a card` |
| Sample / Export | `Sample` / `Export .md` | `Sample deck` / `Export Markdown` |
| Editor placeholder | `Write the card. Link with [[Other card title]].` | `One idea. Link with [[Another card]].` |
| AI heading | `Link & polish` + API disclaimer | `Sharpen this card` / `Tag it. Tighten it. Find the cards it should touch.` |
| AI actions | `Auto-tag` / `Summarize` / `Suggest links` | `Tag` / `Tighten` / `Find links` |
| Backlinks empty | `No cards link here yet…` | `Nothing points here yet…` |

## Core loop (first visit)
SAMPLE deck → `/` search → open card → **Find links** (ink draw) → Tag/Tighten → Export Markdown.
